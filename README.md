## Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Fonts:** Geist (Sans & Mono)

## Secciones

- Hero / About / Tech Stack / Featured Projects / Experience / Education / Contact
- Diseño oscuro con linea de tiempo interactiva y animaciones al hacer scroll
- Responsive (mobile-first), SEO, Open Graph, favicon generado dinamicamente

## Clonar y ejecutar

```bash
git clone https://github.com/RamiroBogado/portfolio.git
cd portfolio
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
